# Ricardo Prazeres — Automações e integrações

Portfólio profissional de Ricardo Prazeres, gestor de automações para operações digitais e lançamentos.

[Ver site publicado](https://ricardo-prazeres-automacoes.vercel.app/)

## Proposta

O site apresenta, de forma direta, três frentes de trabalho:

- automações e integrações;
- operações de lançamentos;
- IA aplicada ao atendimento.

O conteúdo evita métricas, depoimentos e promessas comerciais sem fonte pública. Os exemplos descrevem escopos e ferramentas, sem atribuí-los a clientes específicos.

## Interface

![Versão desktop](screenshots/desktop.png)

![Versão mobile](screenshots/mobile.png)

O projeto utiliza uma direção visual editorial e minimalista: fundo branco quente, texto quase preto, verde-petróleo como única cor de destaque, tipografia Manrope e componentes com bordas discretas.

## Tecnologia

O site permanece simples e sem framework:

- HTML semântico;
- CSS responsivo, mobile-first;
- JavaScript apenas para o menu móvel e o ano do rodapé;
- imagens otimizadas para a web;
- metadados Open Graph, favicon, `robots.txt` e `sitemap.xml`.

## Executar localmente

Sirva a pasta raiz com qualquer servidor HTTP estático. Por exemplo:

```bash
python3 -m http.server 4173
```

Depois, acesse `http://localhost:4173/`.
