# Ricardo Prazeres — Automações

Site profissional de Ricardo Prazeres, gestor de automações para lançamentos digitais.

O projeto é uma página estática, leve e sem dependências: HTML, CSS e JavaScript. A direção visual é editorial e minimalista, com foco em conteúdo, legibilidade e contato direto pelo WhatsApp.

## Conteúdo

- proposta de valor e experiência profissional;
- serviços para captação, comunicação, recuperação e integrações;
- processo de trabalho;
- apresentação profissional;
- formulário que abre uma conversa preenchida no WhatsApp.

## Executar localmente

Abra `index.html` diretamente ou use qualquer servidor estático local.
